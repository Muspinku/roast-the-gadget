One original line, at most 200 characters, roasting a gadget used every day: wireless earbuds that drop out mid-sentence like tiny divorce lawyers. A judge model compares entries two at a time and the funniest, freshest, neatest line takes the reward.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18 or later, standard library only — nothing to install. The program writes the entry to `out/entry.txt`.
